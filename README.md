# sniflot

Персональный self-hosted агрегатор объявлений и монитор цен: один поиск по
нескольким площадкам, сохранённые поиски с уведомлениями о новых объявлениях,
отслеживание карточек с историей цен, Telegram, REST API и MCP для AI-агентов.

Один процесс (FastAPI + фоновый планировщик), SQLite в одном файле, без
Redis/Celery/браузера.

## Состояние источников

| Источник | Статус | Как получает данные |
|---|---|---|
| Wildberries | включён | публичный JSON-поиск и карточка |
| Avito | **экспериментально**, выключен | HTML страницы, без обхода защиты — на многих IP не работает |
| Ozon, Яндекс Маркет | нет | нужен браузер, запланировано на v0.3 |

Ни один источник не проверен вживую из среды разработки (сетевая политика не
пускала к площадкам). Проверьте на своём сервере командой `sniflot probe` — см.
[docs/sources.md](docs/sources.md), там же все известные ограничения.

## Возможности (v0.1)

- **Поиск** по выбранным площадкам: цена от/до, регион, состояние, исключающие
  слова, сортировка по цене, дате и выгодности; дубликаты убираются; таблица или карточки.
- **Сохранённые поиски** по расписанию: первый прогон запоминает текущую выдачу,
  дальше — уведомления о новых объявлениях (одним сообщением) и о снижении цены
  на заданный процент.
- **Отслеживание карточки** по ссылке: история цены (пишутся только изменения),
  целевая цена, падение на N %, «нет в наличии»/«снова в наличии», «снято с публикации».
- **Оценка выгодности** обычной статистикой: процент ниже медианы выдачи и ниже
  своей истории; «подозрительно дёшево» — ниже 40 % медианы (часто аксессуар,
  подделка или мошенник); резкое падение больше чем вдвое помечается в уведомлении.
- **Блокировки**: 403/429/капча ставят источник на паузу с нарастанием (без
  повторов в цикле), приходит одно уведомление; блокировка никогда не считается
  «объявление пропало».
- **Интерфейс**: дашборд, поиск, страница поиска, карточка с графиком цены,
  избранное, настройки, bookmarklet «добавить текущую страницу», мобильная вёрстка,
  тёмная тема по системной настройке.
- **Экспорт** истории цены в CSV/JSON.
- **REST API** `/api/v1` (Swagger на `/docs`) и **MCP-сервер** `sniflot mcp`.

## Запуск в Docker

```bash
git clone https://github.com/tiptop32/sniflot && cd sniflot
cp .env.example .env          # Telegram, пароль, регион — по желанию
mkdir -p data && sudo chown 1000 data
docker compose up -d --build
docker compose exec sniflot sniflot probe wildberries "наушники"
```

Интерфейс: http://127.0.0.1:8000. По умолчанию порт слушает только localhost;
чтобы открыть его в домашней сети, задайте `SNIFLOT_BIND=0.0.0.0` в окружении
compose **и** `SNIFLOT_AUTH_USER`/`SNIFLOT_AUTH_PASSWORD` в `.env`.

Если Docker Hub ограничивает скачивание, можно взять базовый образ из зеркала:
`docker compose build --build-arg PYTHON_IMAGE=mirror.gcr.io/library/python:3.12-slim`.

## Запуск без Docker

```bash
python3.11 -m venv .venv && . .venv/bin/activate
pip install -e ".[mcp]"
sniflot probe wildberries "наушники"   # проверка источника
sniflot serve                          # UI + API + планировщик на :8000
```

Все настройки — переменные окружения с префиксом `SNIFLOT_`, список с
пояснениями в [.env.example](.env.example). База — `data/sniflot.db`
(`SNIFLOT_DB_PATH`).

## Telegram

1. Создайте бота у [@BotFather](https://t.me/BotFather), получите токен.
2. Напишите боту любое сообщение, откройте
   `https://api.telegram.org/bot<TOKEN>/getUpdates` и возьмите `chat.id`.
3. Задайте `SNIFLOT_TELEGRAM_BOT_TOKEN` и `SNIFLOT_TELEGRAM_CHAT_ID`, перезапустите,
   нажмите «Отправить тестовое уведомление» в настройках.

Без Telegram события видны на дашборде и в журнале.

## MCP

```json
{"mcpServers": {"sniflot": {"command": "docker", "args": ["compose", "-f", "/path/to/sniflot/docker-compose.yml", "exec", "-T", "sniflot", "sniflot", "mcp"]}}}
```

Инструменты: `search_offers`, `list_sources`, `list_watches`, `add_watch`,
`price_history`, `list_searches`, `create_search`, `search_results`. Запрос на
естественном языке («найди наушники до 3000 без чехлов») разбирает агент; сам
sniflot LLM не использует.

## Правила, которых придерживается проект

Не обходит капчу и механизмы контроля доступа, не подделывает TLS-отпечаток,
не покупает cookies и не ротирует прокси, не собирает телефоны продавцов,
держит паузы между запросами. Если площадка закрывает доступ — источник
останавливается и сообщает об этом.

# Этап 3. MVP и план разработки

## Приоритеты

### MVP (v0.1)
1. Адаптер Wildberries (публичный JSON-поиск и карточка), с лимитами, ретраями,
   кэшем, паузой при блокировке.
2. SQLite: объявления, история цен, сохранённые поиски, отслеживания, события.
3. Сохранённые поиски с фильтрами (цена, регион, исключающие слова, сортировка)
   и уведомлением о новых объявлениях и снижении цены.
4. Отслеживание карточки по URL: история, целевая цена, падение на N %, удаление.
5. Объединение результатов, дедупликация, сортировка по цене / дате / выгодности,
   метка «подозрительно дёшево».
6. Веб-интерфейс: дашборд, поиск, карточка с графиком, избранное, настройки.
7. Telegram-уведомления.
8. REST API, экспорт истории в CSV/JSON, bookmarklet «добавить по URL».
9. Docker Compose, тесты без сети (фикстуры + `httpx.MockTransport`).
10. `sniflot probe` — проверка источника с реальной сетью на месте установки.

### v0.2
- Avito: доведение экспериментального адаптера по результатам `probe`
  на реальном IP (форматы страниц меняются часто).
- MCP-сервер (уже заложен тонкой обёрткой; расширить инструменты).
- Apprise как канал уведомлений (email, ntfy, Discord, … одной зависимостью).
- Универсальный адаптер «товар по URL» через JSON-LD `Product/Offer`.
- Сопоставление одинаковых товаров на разных площадках (нормализованное
  название + бренд + числовые токены: объём, модель).

### v0.3+
- Ozon и Яндекс Маркет через Playwright (видимый браузер, только карточки по URL,
  редкие проверки) — отдельный опциональный образ.
- Расширение браузера (сейчас — bookmarklet).
- Цена за единицу (шт., мл, г).
- Тихие часы уведомлений, дайджест раз в день.
- Импорт/экспорт всей базы.

## План разработки (каждый шаг — работающий результат)

| # | Шаг | Результат и проверка |
|---|---|---|
| 1 | Каркас: `pyproject`, конфиг из env, `GET /api/v1/health` | `uvicorn` стартует, тест health |
| 2 | Модель `Offer`, интерфейс адаптера, HTTP-слой (лимит, ретраи, кэш, блокировка) | тесты на `MockTransport`: ретрай 5xx, 429 → `BlockedError`, кэш |
| 3 | Адаптер WB: поиск + карточка + разбор URL | тесты на JSON-фикстурах; `sniflot probe wildberries "iphone"` на реальной сети |
| 4 | SQLite-схема, репозиторий, upsert объявлений, история только при изменении | тесты репозитория на временной БД |
| 5 | Сервис: разовый поиск по нескольким источникам, нормализация, дедуп, сортировка, оценки | тесты сервиса с фейковым источником |
| 6 | Сохранённые поиски + отслеживания + события + планировщик | тесты: базовая линия, новое объявление, падение цены, удаление, пауза источника |
| 7 | Telegram-уведомления | тест форматирования и отправки через `MockTransport` |
| 8 | REST API | тесты через `TestClient` |
| 9 | Веб-интерфейс + SVG-график + bookmarklet | тесты рендеринга страниц |
| 10 | Docker Compose | `docker compose config`, сборка образа |
| 11 | Avito (экспериментально, выключен по умолчанию) | тесты на фикстурах блок-страницы и каталога |
| 12 | MCP | тест списка инструментов |

# Источники и их ограничения

Статус на 2026-10-26. «Проверено» ниже означает только офлайн-тесты на
синтетических фикстурах (`tests/fixtures`). Живой запрос к площадкам из среды
разработки был невозможен: сетевая политика отклоняла соединения с их доменами.
Перед тем как полагаться на источник, проверьте его на своём сервере:

```bash
docker compose exec sniflot sniflot probe avito "iphone 13"
docker compose exec sniflot sniflot probe ozon "наушники"
docker compose exec sniflot sniflot probe wildberries "наушники"
```

`probe` делает один поиск и одно чтение карточки и печатает, что получено или
какая ошибка. Код возврата 0 — источник работает.

## Приоритет и способ загрузки

| Источник | Приоритет | Загрузка | Образ |
|---|---|---|---|
| Avito | 1 | настоящий Chromium (`SNIFLOT_AVITO_BACKEND=browser`, по умолчанию в `full`) или HTTP | full / slim |
| Ozon | 1 | только настоящий Chromium | full |
| Wildberries | 2 | HTTP, публичный JSON | full / slim |

Браузер — обычный Chromium через Playwright: без stealth-патчей, без подмены
отпечатков, `navigator.webdriver` не скрывается, капча не решается. В образе
`full` он работает в видимом режиме на виртуальном дисплее (Xvfb), потому что
headless-режим площадки проверяют строже. Профиль (cookies) хранится в
`/data/browser`, как у обычного браузера. Одновременно грузится одна страница,
между загрузками одной площадки — пауза (Avito 30 с, Ozon 20 с), картинки,
шрифты и видео не скачиваются.

Если площадка показывает проверку «вы не робот» или «доступ ограничен»,
источник встаёт на паузу (Avito и Ozon — 1 ч, удваивается до 12 ч), в Telegram
приходит одно уведомление, остальные источники продолжают работать. Переход с
HTTP на браузер после блокировки автоматически не делается: блокировка — это
ответ площадки, а не повод сменить инструмент.

## Avito

| | |
|---|---|
| Данные | встроенное состояние страницы `<script type="mime/invalid" data-mfe-state>` → `loaderData.data.catalog.items`; запасной вариант — `window.__initialData__`. Одинаково для HTTP и браузера |
| Фильтры | текст, цена (`pmin`/`pmax`), сортировка, регион (slug: `moskva`, `sankt-peterburg`, `all`); для остальных фильтров вставьте в поиск ссылку на выдачу Avito |
| Пагинация | по ссылке `catalog.pager.next` |
| Отслеживание | карточка по ссылке; «снято с публикации» → статус «снято» и уведомление |

Ограничения:
- Защита Avito — фаервол по IP, капча, проверка TLS-отпечатка. Браузерный режим
  даёт настоящий TLS Chrome, но от блокировки по IP не спасает: с серверных/VPS
  адресов Avito, скорее всего, не будет работать. Нужен домашний российский IP.
  Авторы avito-mcp-plugin сообщают о 403/429 после 2–3 запросов даже с домашнего
  IP при частых запросах — поэтому интервалы большие.
- Разметка меняется часто. При изменении адаптер вернёт ошибку «формат мог
  измениться», а не пустой результат.
- Фильтр «новое/б/у» зависит от категории — задавайте его ссылкой.
- Телефоны и данные продавцов не собираются.

## Ozon

| | |
|---|---|
| Поиск | `ozon.ru/search/?text=…&sorting=…&currency_price=мин;макс&page=N` |
| Данные выдачи | 1) состояние виджета `div[id^=state-searchResultsV2][data-state]` → `items`; 2) если его нет — отрисованный DOM: ссылки `/product/<slug>-<id>/` и суммы `₽` внутри той же плитки |
| Карточка | JSON-LD `Product` (`offers.price`, `availability`), состояние `webPrice` (цена без Ozon Карты, старая цена, `isAvailable`), `webOutOfStock`, `<h1>` |
| Пагинация | `page=N`, останавливается, когда страница не даёт новых товаров |
| Отслеживание | по ссылке или артикулу (`/product/<id>/`), удаление → 404 / «Такой страницы не существует» |

Ограничения:
- Разметка Ozon закрыта и меняется. Форматы выше взяты из открытых проектов и
  прошлых версий сайта; на 2026-10 они вживую **не проверены**. Разбор
  многослойный, и страница без товаров и без «ничего не нашлось» считается
  ошибкой формата, а не пустой выдачей. Заглушка антибота никогда не
  превращается в «товар» (покрыто тестом).
- Цена — обычная, без скидки по Ozon Карте.
- Регион берётся из профиля браузера (по умолчанию Москва); параметр «регион» игнорируется.
- Только новые товары; уценка/б/у не поддерживаются.

## Wildberries

| | |
|---|---|
| Способ | публичный JSON: поиск `search.wb.ru/exactmatch/ru/common/v{N}/search`, карточка `card.wb.ru/cards/v4/detail` |
| Браузер / авторизация | не нужны |
| Фильтры на стороне WB | цена (`priceU`), сортировка, регион (`dest`) |
| Фильтры на нашей стороне | исключающие слова, повторная проверка цены |
| Пагинация | до 5 страниц по ~100 товаров, останавливается на неполной странице |
| Частота | ≥ 1,5 с между запросами (`SNIFLOT_WB_MIN_INTERVAL`), ответы поиска кэшируются на 2 мин |
| Блокировка | 403/429 → пауза 10 мин, удваивается при повторе (до 12 ч), уведомление в Telegram |

Известные ограничения:
- Эндпоинт недокументирован; номер версии в пути менялся (v4 → v9 → v13 → v18).
  Адаптер пробует версии из `SNIFLOT_WB_SEARCH_URLS` по порядку и запоминает
  ответившую. Если все отвечают 404 — найдите актуальный URL во вкладке Network
  браузера на wildberries.ru и задайте переменную.
- Цена — та, что видит неавторизованный покупатель: без скидки WB Кошелька и
  персональных скидок.
- Цена и наличие зависят от `dest` (регион/склад). По умолчанию Москва.
- Товар с несколькими размерами/вариантами показывается с минимальной ценой.
- Картинки не показываются: адрес CDN (`basket-NN`) вычисляется по таблице,
  которая часто меняется, — неверные ссылки хуже отсутствующих.
- Только новые товары; фильтр «б/у» для WB возвращает пустой результат с предупреждением.

## Яндекс Маркет — не поддерживается

Нужен браузер, как Ozon. Браузерный слой уже есть, адаптер — следующий по плану.

## Как добавить источник

1. Создайте `src/sniflot/sources/<name>.py` с классом, реализующим протокол
   `Source` из `sources/base.py`: `info`, `search`, `fetch`, `parse_ref`, `aclose`.
2. Для HTTP используйте `HttpClient` — он даёт лимит частоты, ретраи, кэш и
   превращает 403/429 в `BlockedError`, 404 — в `NotFoundError`.
3. Страницу блокировки распознавайте явно и бросайте `BlockedError`; непонятный
   ответ — `SourceError`. Никогда не возвращайте пустой список вместо ошибки.
4. Зарегистрируйте источник в `sources/registry.py` и добавьте настройки в `config.py`.
5. Тесты — на фикстурах через `httpx.MockTransport` (см. `tests/test_wildberries.py`).
